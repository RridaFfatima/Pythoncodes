# Python Programming

A collection of Python programs, practice exercises, and problem-solving solutions developed while learning and exploring Python programming.

This repository documents my programming practice, reinforces fundamental concepts, and serves as a reference for solving problems using Python.

## Topics Covered

- **Variables and Data Types** — Integers, floats, strings, and booleans
- **Input and Output** — User input and formatted output
- **Operators** — Arithmetic, comparison, logical, and assignment operators
- **Conditional Statements** — `if`, `elif`, and `else`
- **Loops** — `for` and `while` loops
- **Functions** — Defining functions, parameters, return values, and reusable code
- **Strings** — String manipulation and character operations
- **Lists and Collections** — Working with lists and other basic data structures
- **Problem Solving** — Logic building and programming exercises
- **Practical Programs** — Scenario-based problems and small programming tasks

## Technologies

- Python 3
- Visual Studio Code

## Purpose

- Strengthen Python programming fundamentals.
- Improve logical thinking and problem-solving skills.
- Practice concepts through hands-on coding.
- Maintain a collection of programs for future reference.

## Repository Structure

Programs are organized into Python source files (`.py`), with each file containing a particular exercise, concept, or problem solution.

## Getting Started

1. Install Python 3.
2. Clone this repository.
3. Open a Python file in your preferred code editor.
4. Run the program using:

```bash
python3 filename.py
```

Replace `filename.py` with the name of the Python file you want to execute.
